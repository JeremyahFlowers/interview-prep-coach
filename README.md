# Interview Prep Coach

A free, local-first interview-prep app: spaced repetition, pattern recognition, and a well-being model that treats burnout as a
first-class failure. It runs entirely in your browser, with no account, no tracker and no prices.

**Try it:** https://jeremyahflowers.github.io/interview-prep-coach/ (a made-up-data copy is at `/demo/`).

This repository holds only the built, static site (in `site/`), published with GitHub Pages. The app's source is developed
elsewhere and is not part of this repository.

If it helps you, a star on this repository is the best way to say so.
